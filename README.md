# Driftline At Home

Customer-facing website for Driftline At Home, an in-home meal-prep service serving Oregon’s North Coast.

## Included

- Responsive customer homepage
- Interactive meal-package selector
- Availability request flow
- Rotating-menu presentation
- Family and caregiver visit updates
- Service-area and pricing details

Built with Next.js, React, TypeScript, Tailwind CSS, and Vinext.
